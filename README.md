# 會計學刷題站(四技二專 商管群 專業科目(二)・會計學)

110–114 學年度模擬考「專二」會計學題庫(約 560 題),附詳細解題步驟。功能:自由練習(依 17 個單元/學年/次別篩選)、模擬考(限時)、錯題本、錯題練習卷(列印/存 PDF)、姓名+4 位數密碼登入。

網址:啟用 GitHub Pages(Settings → Pages → Branch: main / root)後為 `https://lrw-crypto.github.io/Accounting/`

雲端同步(選用):依 `雲端設定說明.md` 部署 Apps Script,把網址貼進 `config.js` 的 `CLOUD_URL`。
